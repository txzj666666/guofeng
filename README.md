> 墨黑为纸 · 金线为骨 · 朱砂为魂 · 水墨为境

传承千年名将智慧的国风养成交互作品。**单文件自包含 HTML**，双击 `index.html` 即开卷，无需服务器、无需联网。

## 数值公式（每行可追溯）

```
经验 Σ[(Lv-1)×100 + Lv²×5]      Lv 从「等级 +1」累加至「目标级」
银两 = 等级差 × 6000 × 兵种系数
兵书 = ⌊ 等级差 / 10 ⌋ × 2 × 兵种系数  (向上取整)
丹药 = ⌊ 等级差 / 5  ⌋ × 4 × 兵种系数  (向上取整，最低 2)
时日 = ⌈ 总经验 / 日 XP ⌉
成色 = 武力×0.4 + 统率×0.6
```

切换 12 位名将 / 4 兵种 / 4 修炼路径任意一项 → 数值实时重算。

## 重新生成引导式截图

```bash
npm install                  # 安装 playwright
node screenshot.js           # 生成 14 张原图
python annotate.py           # 加注引导气泡（需要 Pillow）
```
